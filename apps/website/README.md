# Gym4Me Website

Marketing website for Gym4Me. Shares `@repo/ui`, `@repo/theme`, `@repo/fonts`, `@repo/icons`, and `@repo/i18n` with the rest of the monorepo.

## Develop

From the repo root:

```sh
npm run dev:website
```

Or:

```sh
npx turbo run dev --filter=website
```

App runs at [http://localhost:8080](http://localhost:8080).
