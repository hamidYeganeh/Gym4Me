# Gym4Me Business Panel

پنل وب مستقل مالکان باشگاه. این اپ از Session حساب کاربری استفاده می‌کند، اما پیش از نمایش Routeهای محافظت‌شده از API یک Access Token تازه با Context نقش `club_owner` دریافت می‌کند.

## اجرا

```bash
npm run dev:business
```

پنل روی `http://localhost:8083` و API پیش‌فرض روی `http://localhost:8088/api/v1` در نظر گرفته شده است. برای تغییر آدرس API، فایل `.env.local` را از `.env.local.example` بسازید.

## مرز محصول

- اپ موبایل فقط تجربه Athlete/Coach و onboarding نقش‌ها را نگه می‌دارد.
- عملیات Owner از مسیرهای قدیمی `/owner/*` به این پنل redirect می‌شود.
- Session پنل کسب‌وکار با پسوند `.business` از Session اپ موبایل و ادمین جداست.
- مجوز نهایی همه عملیات در API و براساس Active Access Context و Scope بررسی می‌شود.

## وضعیت مهاجرت

داشبورد و فهرست باشگاه‌ها به API واقعی متصل‌اند. Routeهای اعضا، رزرو، مالی، پرسنل، عملیات و تنظیمات ایجاد شده‌اند و مقصد انتقال UIهای owner موجود هستند. تا پایان انتقال و جابه‌جایی تست‌های آفلاین، سورس owner قدیمی موبایل حذف نمی‌شود؛ Routeهای آن دیگر قابل اجرا نیستند.
