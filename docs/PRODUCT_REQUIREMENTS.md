# نیازمندی‌های نسخه تجاری اول Gym4Me

## هدف

کاربر باید بتواند از ثبت‌نام و پیدا کردن باشگاه یا مربی تا رزرو، پرداخت، استفاده از عضویت و مدیریت کیف پول را در Gym4Me انجام دهد. باشگاه، مربی، سازمان و ادمین نیز باید ابزار عملیاتی و مالی متناسب با Scope خود داشته باشند.

## محصولات

1. اپ موبایل مشترک ورزشکار و مربی با Role Switcher.
2. پنل وب باشگاه و پرسنل با Scope سازمان و شعبه.
3. پنل وب ادمین با دسترسی سراسری و Audit کامل.
4. وب‌سایت عمومی و SEO در فاز رابط کاربری.
5. API مرکزی، Worker، اعلان، پیامک و پرداخت.

## نقش‌ها

- Athlete
- Coach
- Club Owner
- Branch Manager
- Reception
- Finance Staff
- Corporate Admin
- System Admin roles: Super Admin، User Admin، Finance Admin، Verification Admin، Content Moderator و Support Agent

یک کاربر می‌تواند چند RoleAssignment هم‌زمان و در Scopeهای متفاوت داشته باشد.

## قابلیت‌های ضروری

### حساب و امنیت

- ورود/ثبت‌نام با OTP کاوه‌نگار
- ورود با رمز عبور
- تعیین، تغییر و بازیابی رمز
- Refresh Token چرخشی
- خروج از دستگاه فعلی یا همه دستگاه‌ها
- مدیریت Session و Device
- پروفایل ورزشکار و مربی

### عرضه و جست‌وجو

- سازمان، باشگاه، شعبه، مربی، منبع و Offering
- درخت رشته‌های ورزشی قابل مدیریت توسط ادمین: دسته‌بندی ورزش ← ورزش ← شاخه اختیاری
- جست‌وجو بر اساس رشته، شهر، فاصله، جنسیت، قیمت، امتیاز، امکانات و زمان آزاد
- تأیید مربی و باشگاه

### رزرو

- تکی، دوره‌ای، چندنفره، خانوادگی، کلاس، مربی، زمین/سالن و همراه مربی
- Hold زمان‌دار
- ظرفیت مستقل Resourceها
- State machine و تاریخچه وضعیت
- لغو، No-show، Check-in، تکمیل و بازپرداخت

### مالی

- Quote و Price Snapshot
- پرداخت درگاه و پرداخت ترکیبی
- کیف پول نقدی، هدیه، تبلیغاتی و سازمانی
- Double-entry Ledger
- Invoice، Refund، Commission، Settlement و Reconciliation

### عضویت

- عضویت باشگاه: مدت‌دار، تعداد ورود، نامحدود، خانوادگی، سازمانی و چندشعبه‌ای
- پلن پولی Gym4Me برای Athlete، Coach، Club و Corporate در Backlog محصول نگهداری می‌شود و جزئیات آن بعداً تصمیم‌گیری خواهد شد.

### تبلیغات

- Featured listing و جایگاه‌های داخلی
- Targeting، Budget، Impression، Click و Conversion
- تأیید محتوای تبلیغ توسط ادمین

### مدیریت داینامیک

- تعریف فیلد، گروه فیلد، فرم، Validation و Visibility
- Taxonomy و Termهای تو‌در‌تو
- Workflow، Status و Transition
- Template اعلان، Plan Entitlement و Feature Flag

## خارج از محدوده فعلی

- UI نهایی
- شبکه اجتماعی و Feed
- برنامه تمرینی، تغذیه و کنترل پیشرفت
- تماس و ویدئوی داخلی
- قابلیت‌های منابع انسانی مانند شیفت، مرخصی، حضور اداری، حقوق و دستمزد و ارزیابی کارکنان
- انتقال کیف پول بین ورزشکاران

پنل باشگاه ابزار منابع انسانی نیست. مدیریت پرسنل در این محصول فقط شامل دعوت، نقش و دسترسی عملیاتی آن‌ها در سازمان، باشگاه و شعبه است. تمرکز محصول روی مدیریت باشگاه، اعضا، مربیان، شاگردان، رزروها و ارتباط با ورزشکاران باقی می‌ماند.

## معیارهای پذیرش زیرساخت

- ساخت همه Workspaceها موفق باشد.
- API Health و OpenAPI در دسترس باشند.
- مدل‌های داده قابلیت Migration داشته باشند.
- مسیرهای Account/Auth و Meta قابل اجرا باشند.
- Permission فقط در UI کنترل نشود و Backend Guard داشته باشد.
- اپ موبایل Static Export تولید کند و `webDir` Capacitor برابر `out` باشد.
